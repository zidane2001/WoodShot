## 🔧 BACKEND API ENDPOINTS

### AUTHENTICATION ROUTES
```
POST /api/auth/register
- Register new user
- Body: {email, password, first_name, last_name, phone}
- Response: {access_token, user: {id, email, first_name, last_name}}

POST /api/auth/login
- User login
- Body: {email, password}
- Response: {access_token, user: {id, email, first_name, last_name}}

POST /api/auth/admin
- Admin access with PIN
- Body: {pin}
- Response: {access_token, is_admin: true}

GET /api/auth/me
- Get current user info (JWT required)
- Response: {id, email, first_name, last_name, phone, is_active, is_admin}
```

### PRODUCT MANAGEMENT
```
GET /api/products
- Get all available products
- Response: [{id, name, description, wood_type, price_per_unit, unit, stock_quantity, image_url, specifications}]

POST /api/products (Admin only)
- Create new product
- Form data: name, description, wood_type, price_per_unit, unit, stock_quantity, specifications, image(file)
- Response: {id, message}

PUT /api/products/<id> (Admin only)
- Update product
- Form data: same as create
- Response: {message}

DELETE /api/products/<id> (Admin only)
- Delete product
- Response: {message}
```

### ADDRESS MANAGEMENT
```
GET /api/addresses (JWT required)
- Get user's addresses
- Response: [{id, street, city, postal_code, country, is_default}]

POST /api/addresses (JWT required)
- Create new address
- Body: {street, city, postal_code, country, is_default}
- Response: {id, message}

PUT /api/addresses/<id> (JWT required)
- Update address
- Body: {street, city, postal_code, country, is_default}
- Response: {message}

DELETE /api/addresses/<id> (JWT required)
- Delete address
- Response: {message}
```

### ORDER MANAGEMENT
```
GET /api/orders (JWT required)
- Get user's orders or all orders (Admin)
- Response: [{id, total_amount, status, created_at, user_id}]

POST /api/orders (JWT required)
- Create new order
- Body: {items: [{product_id, quantity}], customer, delivery, total, paymentMethod}
- Response: {id, message, total_amount}

PUT /api/orders/<id> (JWT required)
- Update order status
- Body: {status}
- Response: {message}
```

### DELIVERY MANAGEMENT
```
GET /api/deliveries (JWT required)
- Get user's deliveries or all deliveries (Admin)
- Response: [{id, order_id, address: {...}, delivery_date, status, tracking_number, notes}]

POST /api/deliveries (Admin only)
- Create delivery
- Body: {order_id, address_id, delivery_date, status, tracking_number, notes}
- Response: {id, message}

PUT /api/deliveries/<id> (Admin only)
- Update delivery
- Body: {delivery_date, status, tracking_number, notes}
- Response: {message}
```

### PAYMENT SYSTEM
```
POST /api/payments/create
- Create payment (crypto or bank)
- Body: {amount, currency, payment_method, crypto_currency?, order_id, customer_email, customer_name, description}
- Response: {payment_url, payment_id, order_id, status, payment_method, ...}

POST /api/payments/callback
- Payment gateway callback
- Body: {payment_status, order_id}
- Response: {status: 'ok'}
```

## 🔄 WORKFLOW

1. User browses products on homepage
2. Adds items to cart
3. Proceeds to checkout
4. Fills personal and delivery information
5. Selects payment method (Bank/Crypto)
6. Submits order and gets payment instructions
7. Completes payment manually
8. Receives order confirmation
9. Admin manages orders and deliveries
10. Customer tracks delivery status

This is a complete e-commerce solution for wood products with modern web technologies, secure payments, and comprehensive admin features.
